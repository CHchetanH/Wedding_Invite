# Chetan & Monika: wedding invitation

Static site (HTML, CSS, JS). No build step.

| Link | Who it is for | Events shown |
| --- | --- | --- |
| `/main` | close family and friends | Haldi, Sangeet, Wedding, Reception |
| `/guest` | all other guests (also the root `/`) | Wedding, Reception |

- All wording, dates, venues and the RSVP number are in `content.js` (Marathi, English, Hindi).
- The page rotates Marathi, English, Hindi every 10 seconds; the doors open on tap or after 5 seconds.
- Deploy: drag this folder onto Netlify Drop, or connect the repo to Netlify, Cloudflare Pages or GitHub Pages.
